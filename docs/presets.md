# Analysis presets

[← Back to overview](../README.md)

Lighthouse ships 23 point-and-click analyses (tab **Statistics**) for the questions that come up in almost every case. Each is backed by **one hand-reviewed SQL query**; none is generated by the language model. The same data and the same input therefore always give the same result, and the query can be shown and disclosed if challenged.

The query assistant also routes matching questions to these presets (see [Query assistant](query-assistant.md)).

"Cell site" below means the operator-reported coordinate of the serving cell in the record. "Identifier" means a phone number (MSISDN), an IMSI or a device ID (IMEI).

## Overviews

| Preset | What it finds | Input | Notes and limitations |
|---|---|---|---|
| All phone numbers | Every MSISDN in the records, with number of hits and first/last occurrence. | – | – |
| All identifiers | Every phone number, IMSI and IMEI, by identifier type, with record count and first/last occurrence. | – | – |
| Cell sites in the dataset | Every cell site with record count and first/last occurrence. | – | – |
| Connection type | Classifies each record as telephony, SMS or GPRS/data, from call indicator and network access type. | – | – |
| Party role | Groups by the imported raw party type per phone number/IMSI. | – | The A/B/C-party meaning of this field could not be verified; raw values are shown. |
| Number of transmissions | Records of one identifier, broken down by connection type. | identifier | – |

## Movement and behaviour

| Preset | What it finds | Input | Notes and limitations |
|---|---|---|---|
| Roamers | Phone numbers/IMSIs registered at more than one cell site. | – | – |
| Participants per cell site | Per cell site, the number and list of phone numbers/IMSIs. | – | – |
| Recurring pairs | Pairs of phone numbers registered more than once in the same cell site within 30 minutes. | – | Shared cell, not physical proximity; coincidental matches in busy cells. |
| Twins | Pairs of phone numbers that visited exactly the same set of cell sites. | – | Many trivial matches if an export contains few cells. |
| Presence in area | Whether an identifier was registered within a radius (default 500 m) of a map point. | identifier, point, radius | Radius approximated by a bounding box without latitude correction; refers to cell coordinates, not device positions. |

## Identity and device

| Preset | What it finds | Input | Notes and limitations |
|---|---|---|---|
| Switchers (device/SIM swap) | IMSIs seen with more than one IMEI (device swap) and IMEIs seen with more than one IMSI (SIM swap). | – | German casework term: *Wechsler*. |
| Cross-source hits | IMSIs, phone numbers or IMEIs that occur in more than one data request/source file. | – | – |
| Similar phone numbers | Phone numbers that differ only in their last two digits (possibly a jointly issued block). | – | Heuristic. |
| Device type for an IMEI | Local records of an IMEI and, optionally, an online lookup of its type allocation code (make/model). | IMEI | Online lookup only with a configured API key; sends the 8-digit TAC. |

## Country codes

| Preset | What it finds | Input | Notes and limitations |
|---|---|---|---|
| Domestic/foreign numbers | Separates domestic from foreign numbers by calling code; shows the country for recognised codes. | – | Numbering-plan heuristic: the country where a number is registered, **not** the nationality or location of its holder. |
| Numbers from a country | Filters numbers by an entered calling code. | calling code | Same heuristic. |
| Country overview | Count of all numbers per recognised country. | – | Unrecognised codes shown as raw prefix. |

## Network and co-location

| Preset | What it finds | Input | Notes and limitations |
|---|---|---|---|
| Connections of an identifier | All records of an identifier in chronological order, with cell site, time and connection type (empty table = no hit). | identifier | – |
| Call/SMS partners | For calls/SMS of an identifier, the counterpart via the shared session identifier, with its cell site and time. | identifier | Assumes both legs share the session ID; not yet verified on real telephony data. |
| Identifiers near an identifier | Other identifiers in the same record (session ID) or in the same cell site within ±30 minutes. | identifier | Shared cell, not proximity. |
| Most frequent companion | Other identifiers most often in the same cell site within ±30 minutes, by frequency. | identifier | Shared cell, not proximity. |
| Partners in the same cell | Pairs linked as call/SMS partners via session ID and registered in the same cell site at the time. | – | Assumes shared session ID. |
